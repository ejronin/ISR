# Social Sharing Specification

Canonical public URL:

`https://ejronin.github.io/ISR/`

Required `<head>` metadata:

```html
<link rel="canonical" href="https://ejronin.github.io/ISR/">
<meta property="og:type" content="website">
<meta property="og:title" content="Iran War Public Evidence Atlas">
<meta property="og:description" content="A source-linked public OSINT dashboard tracking verified events, losses, damage, operational effects, economics, bargaining shifts and information-war claims in the 2026 Iran conflict.">
<meta property="og:url" content="https://ejronin.github.io/ISR/">
<meta property="og:image" content="https://ejronin.github.io/ISR/assets/social-preview.png">
<meta name="twitter:card" content="summary_large_image">
<meta name="twitter:title" content="Iran War Public Evidence Atlas">
<meta name="twitter:description" content="Source-linked public OSINT dashboard for the 2026 Iran conflict.">
<meta name="twitter:image" content="https://ejronin.github.io/ISR/assets/social-preview.png">
```

The social-preview image should be 1200×630, committed in the repository, legible at thumbnail size, and avoid partisan slogans or unverified claims.
