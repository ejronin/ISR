# Iran War Public Evidence Atlas v2.7

Public OSINT dashboard for the 2026 Iran war. It separates verified physical damage, operational effect, actor claims, analytic assessment, economic effects, missile/drone performance, and information-environment claims.

## Files
- `index.html` — complete dashboard
- `data/information_war_claims_v2_7.csv` — public claim-check export
- `data/information_war_claims_v2_7.json` — same claim ledger in JSON
- `data/influence_networks_v2_7.json` — ISD-derived network metrics used by the information-war section
- `.nojekyll` — GitHub Pages compatibility

## Publication
GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

Expected project URL for this repository: `https://ejronin.github.io/ISR/`

## Evidence policy
A named person/page is not designated a disinformation actor solely because of political alignment. Verdicts attach to specific preserved claims. Government/state-media claims establish what the actor said but do not self-verify physical effects. Weak or unresolved evidence remains labeled. Verdict revisions should be logged rather than silently overwritten.
