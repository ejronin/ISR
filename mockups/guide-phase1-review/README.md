# Phase 1 Guide Facelift Review Mockups

**Status:** review-only visual package  
**Authority:** presentation only  
**Controlling specification:** `docs/GUIDE_PAGE_VISUAL_ARCHITECTURE.md` at/after PR #280  
**Production implementation:** not authorized by this package

These mockups are the renderer review tranche for the seven Phase 1 analytical archetypes:

1. Hormuz & Economy
2. Oil & Economic Effects
3. Campaigns & Strikes
4. Casualties & Losses
5. Timeline
6. Web of Lies
7. Who's Involved

Every page has desktop and mobile references.

## Evidence boundary

The mockups use accepted field/category placeholders where embedding exact current data is unnecessary for layout review. Placeholder geometry, bars, nodes, and positions are presentation scaffolding only; they are not factual values, new map geometry, new WOL relationships, or new adjudications.

The production renderer must bind only existing accepted read-model data.

No mockup authorizes changes to accepted wording, evidence, adjudication, chronology, map points, route geometry/IDs, economic calculations/series, WOL/Lie Ledger semantics, EvidenceDrawer behavior, ROOK/Evidence Locker behavior, or release behavior.

## Acceptance focus

- **Hormuz & Economy:** protected economic visualization remains; cross-highlighting is contextual, not causal.
- **Oil & Economic Effects:** Trend / Compare / Event Context are denominator-safe; mechanism / observed / potential-watch remain distinct.
- **Campaigns & Strikes:** selected record cannot disappear; physical damage and operational effect remain independent.
- **Casualties & Losses:** accounting, not scorekeeping; unknown is never zero.
- **Timeline:** Selected Period Summary is mandatory; recorded-event density is not operational intensity.
- **Web of Lies:** node/edge grammar maps only accepted WOL semantics. Current accepted graph classes shown in the legend include `BULLSHITTER`, `MEGAPHONE`, `AMPLIFIES_BULLSHIT`, `SELF_AMPLIFICATION`, and `EXTERNAL_AMPLIFICATION`; the mockup does not add classes or edges.
- **Who's Involved:** geography → accepted actor family → selected detail; non-state actors never receive invented map points.
