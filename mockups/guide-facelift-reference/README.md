# Guide Facelift Reference Mockups

These SVGs are review artifacts for the whole-site facelift reference sweep. They are deliberately isolated from production routing and runtime code.

- 29 desktop references: all 27 public routes plus Lie Ledger case dossier and WOL actor dossier.
- 21 mobile references for map/data/network-heavy pages and dossier states.
- Values are represented as **accepted current value** where the visual slot is important but the reference package must not duplicate or freeze live evidence.
- Shapes/lines show composition and visual-device intent, not new evidence, coordinates, relationships, or calculations.
